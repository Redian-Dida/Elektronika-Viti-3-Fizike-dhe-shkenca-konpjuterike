# Elektronika-Viti-3-Fizike-dhe-shkenca-konpjuterike
​Markdown është një gjuhë e thjeshtë formatimi teksti (lightweight markup language) që ju lejon të shkruani tekst të strukturuar duke përdorur vetëm karaktere të zakonshme nga tastiera. Ajo konvertohet lehtësisht në format HTML ose formate të tjera.  
​Krijuar në vitin 2004 nga John Gruber, qëllimi kryesor i Markdown është të jetë i lehtë për t'u lexuar dhe për t'u shkruar në formën e tij të papërpunuar (raw text).
